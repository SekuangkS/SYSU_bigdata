简历推荐系统架构文档

1. 系统架构概述

本系统采用四阶段推荐流程，结合深度学习和业务规则，实现高效的简历-职位匹配。

前端服务

Web界面
• 基于Flask的RESTful API
• 职位需求输入表单
• 推荐结果展示

核心引擎

推理引擎
• 四阶段推荐流程
• 深度学习模型
• 业务规则引擎

数据存储

数据管理
• 简历CSV数据
• 模型参数文件
• 训练历史记录

2. 四阶段推荐流程

1. 召回阶段

根据基本条件筛选简历：

  • 职位匹配度
  • 学历要求
  • 年龄范围
  • 技能关键词

2. 粗排阶段

使用轻量级模型快速评分：

  • 随机森林模型
  • 特征包括：技能匹配度、学历匹配、经验匹配等
  • 返回Top 200候选

3. 精排阶段

深度学习模型精确匹配：

  • 双塔神经网络结构
  • 256维向量表示
  • Sigmoid输出匹配概率

4. 重排阶段

业务规则和多样性调整：

  • 岗位多样性控制
  • 技能覆盖优化
  • 特殊人才置顶

3. 双塔模型架构

简历塔 (Resume Tower)

输入层
• TF-IDF技能向量 (1000维)
• 学历评分 (专科:1, 本科:2, 硕士+:3)
• 经验评分 (0.5-6.0)
• 项目评分 (小:×1, 中:×2, 大:×4)
• 年龄 (18-60)
• 性别 (男:1, 女:0)
隐藏层1
• Linear(input_dim → 512)
• BatchNorm1d(512)
• ReLU激活
• Dropout(0.3)
• 权重初始化: Kaiming Normal
隐藏层2
• Linear(512 → 256)
• BatchNorm1d(256)
• ReLU激活
• Dropout(0.2)
• L2正则化(λ=0.01)
输出
• 256维简历向量
• 标准化处理
• 向量范数约束

职位塔 (Job Tower)

输入层
• 职位技能向量 (同简历塔)
• 最低学历要求
• 最低经验年限(年)
• 最大年龄限制
• 技能权重参数
隐藏层1
• 结构与简历塔相同
• 参数独立训练
• 共享优化器配置
隐藏层2
• 结构与简历塔相同
• 梯度裁剪(max_norm=1.0)
• 学习率衰减策略
输出
• 256维职位向量
• 与简历向量同空间
• 余弦相似度计算

交互层设计

# 交互层结构 (PyTorch实现) self.interaction_layer = nn.Sequential( nn.Linear(512, 128), # 256+256=512 nn.BatchNorm1d(128), nn.ReLU(), nn.Dropout(0.2), nn.Linear(128, 64), nn.ReLU(), nn.Linear(64, 1), nn.Sigmoid() )

关键设计：

  • 双塔向量拼接后通过3层MLP
  • 最终Sigmoid输出匹配概率(0-1)
  • 训练时使用带权BCE Loss处理类别不平衡
  • 推理时预计算简历向量提升性能

4. 训练与评估

训练配置

优化器 • Adam优化器(lr=0.001)
• 权重衰减(1e-4)
• 梯度裁剪(max_norm=1.0)
• 学习率衰减(patience=5)
损失函数 • BCEWithLogitsLoss
• 正样本权重: 3.0
• Label Smoothing(0.1)
训练策略 • 早停机制(patience=30)
• 批量大小: 256
• 最大epoch: 200
• 验证集比例: 20%

5. 使用说明

训练模型

python train.py

训练过程将生成以下文件：

  • models/recommendation_model.pth - 模型参数
  • models/training_history.json - 训练指标
  • models/metadata.json - 模型元数据

启动服务

python app.py

API端点：

  • POST /api/recommend/deep - 获取推荐结果
  • GET /api/model/info - 获取模型信息
  • GET /api/stats - 获取数据统计
